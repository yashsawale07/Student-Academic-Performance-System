# Student Academic Performance System

## Overview

The Student Academic Performance System is a Python-based application designed to manage student academic information and performance efficiently.

The system allows users to store student details, manage marks, calculate results, search and update student records, and generate academic reports and analysis.

## Features

- Add student records
- Search student records
- View all students
- Update student information
- Delete student records
- Store and manage marks
- Calculate student results
- Generate academic reports
- Analyze student performance
- Dashboard for academic information
- Input validation and error handling

## Technologies Used

- Python
- SQLite
- Git
- GitHub

## Project Modules

- `main.py` – Main program and user interaction
- `student.py` – Student record management
- `marks.py` – Marks management
- `database.py` – Database operations
- `result.py` – Result calculation
- `report.py` – Report generation
- `analysis.py` – Performance analysis
- `dashboard.py` – Dashboard functionality
