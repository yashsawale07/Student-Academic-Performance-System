# Project Requirements

## Functional Requirements

1. The system shall allow users to add student records.
2. The system shall allow users to search student records.
3. The system shall allow users to view all student records.
4. The system shall allow users to update student information.
5. The system shall allow users to delete student records.
6. The system shall allow marks to be added and managed.
7. The system shall calculate student results.
8. The system shall generate academic reports.
9. The system shall analyze student performance.
10. The system shall provide an academic dashboard.
11. The system shall store academic data using SQLite.

## Non-Functional Requirements

### 1. Usability
The system should provide a simple menu-driven interface that is easy to understand and operate.

### 2. Reliability
The system should handle invalid inputs and database errors without crashing unexpectedly.

### 3. Maintainability
The project is divided into separate Python modules so that individual features can be modified easily.

### 4. Performance
The system should perform common operations such as searching, adding, updating, and retrieving student records efficiently.

### 5. Data Integrity
Student and marks information should be stored consistently in the SQLite database.

### 6. Resource Efficiency
The system uses SQLite and modular Python code, making it suitable for running on a normal computer without heavy resources.

## Technical Requirements

- Python 3.x
- SQLite
- Git
- GitHub
- Windows/Linux/macOS compatible environment
